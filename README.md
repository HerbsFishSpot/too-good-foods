# Too Good Foods NYC

Luxury storefront prototype for Too Good Foods NYC, featuring Chef Herb's Signature Chimichurri.

## Current status

**Demo only.** The storefront works as a static preview, but orders are stored in browser local storage. Payment controls are simulations. The dashboard has no authentication. Do not use this version for real transactions or personal customer data.

## Preview

Open `index.html` in a browser or deploy the static project to a preview host. The product photo is referenced as `assets/chef_jar.jpg` and needs to be uploaded separately.

## Production milestones

1. Upload authorized product photos into `assets/` and verify the luxury design.
2. Replace local storage with authenticated server-backed orders and inventory.
3. Add hosted payments via Stripe or PayPal with verified webhooks.
4. Secure the merchant dashboard and define fulfillment, taxes, refunds and notification flows.
5. Test on mobile and launch only after business/compliance checks.
